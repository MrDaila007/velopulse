# BikeComp firmware 0.1.0

Первый инкремент прошивки XIAO nRF52840 Sense: подсчёт импульсов, fixed-point скорость,
дистанция, время движения, автостарт/автопауза и экран SSD1306 с пятью страницами.

## Подключение стенда

| Компонент | XIAO |
| --- | --- |
| OLED VCC / GND | 3V3 / GND |
| OLED SDA / SCL | D4 / D5 |
| Кнопка | D0 и GND |

D0 работает как `INPUT_PULLUP`; короткое нажатие имитирует один импульс open-drain
датчика Холла. OLED должен иметь адрес `0x3C`.

## Команды

```bash
pio test -e native
pio run -e xiao_ble_sense
pio run -e xiao_ble_sense -t upload
pio device monitor -b 115200
```

После загрузки первый импульс запускает поездку и начисляет один оборот. Скорость
появляется после второго корректного импульса. Импульсы быстрее лимита 100 км/ч
отбрасываются; через 3 секунды без импульсов устройство переходит в `PAUSED`.

## Экран

Скорость постоянно отображается крупно. В правом верхнем углу постоянно находится
иконка батареи с процентом; пока BatteryManager/ADC не подключён, прошивка показывает
`--%`. Раз в 4 секунды меняется только нижняя строка: поездка, средняя скорость,
максимальная скорость, время движения и одометр.

Разметка и форматирование находятся в общих C++-модулях `display_layout.cpp` и
`display_formatter.cpp`. Эти же файлы напрямую компилирует OLED-симулятор.
